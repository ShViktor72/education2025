# QA Practice Site

## Как запустить
1. Распакуйте архив.
2. Откройте файл `index.html` в браузере.
3. Нажмите «Сбросить стенд» перед началом нового тестового прогона.

## Тестовые данные
- Email: `qa@test.com`
- Пароль: `Pass1234`

## Что проверять
- Black-box: только UI и требования.
- White-box: код, условия, ветви, unit-проверки.
- Gray-box: UI + API-ответ + БД + логи.

## Важно
В проекте специально оставлены дефекты. Их нужно найти, воспроизвести и оформить в отчетах.
