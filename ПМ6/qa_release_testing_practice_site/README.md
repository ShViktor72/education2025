# QA Release Testing Practice Site

## Как запустить
1. Распакуйте архив.
2. Откройте `index.html` в браузере.
3. Нажмите «Сбросить стенд» перед тестовым прогоном.

## Тема
Smoke testing, regression testing, retesting, alpha testing, beta testing, acceptance testing.

## Роли
- Студент: `student@test.com` / `Stud1234`
- Преподаватель: `teacher@test.com` / `Teach1234`

## Сценарий
Онлайн-платформа EduTask. В релиз 2.4 добавлена функция комментария преподавателя к оценке.

## Важно
В стенде есть намеренные дефекты. Студент не исправляет код, а оформляет QA-артефакты.
